Agent test questions

A test set for each agent of the Financial Report Copilot, run from the Streamlit UI. Each agent gets questions whose answers sit in a page's text, a table or a chart, with the expected response taken from the frozen evaluation set (data/evaluation/financial_report_qa/eval_set_v1.jsonl), the page probe (vlm_page_probe.jsonl) or the agent's design. The Actual response and Pass columns are filled in after a run with the hosted LLM.

All questions cover filings in the 509-filing index (for example BAC, C, JPM, WFC, CVX, NVDA, KO, WMT and MSFT for 2022–2026) and the Vanguard funds in the local N-PORT database. The same list is in output/eval/agent_showcase/questions.json for an automated run.

How to run in Streamlit

  1. Start the API with a hosted LLM (LLM_API_BASE, LLM_API_KEY, LLM_MODEL, DEFAULT_LLM_PROVIDER=hosted), then streamlit run scripts\ui\api_streamlit_app.py and open http://localhost:8501.
  2. Sidebar → Demo settings → Technique: pick the agent named in the section heading (router, agentic_graph, trend_graph, sector_trend_graph, fund_graph). LLM provider: hosted.
  3. Leave Company and Fiscal year on Any, so the agent has to find the company and year in the question itself.
  4. Paste the question, then record the answer, the status line and the cited pages.

What a correct response looks like

  • Status answered (or pending_human_review), with the figure stated and each claim citing a chunk such as annual_report_edgar_ars_C_2025_p0041_vlm0. That ID names the filing (C 2025) and page (41).
  • Verification: support_check: supported and grounding: grounded. The critic found every figure in a cited chunk.
  • Figures: the format may differ. $3,097 million, $3.1 billion and 3,097 in a millions table are all the same answer.
  • Withheld answers: evidence_only means the critic couldn't verify the answer and returned excerpts. That is a safe failure, not a wrong answer, so note whether the expected figure was in the excerpts.
  • Wrong page type: for chart questions, the cited chunk should come from the chart's page. Chunks read by a vision model carry reader: paidVL or qwen3VL, and chart pages also have a page_description chunk.

Automated run

To fill the Actual response columns without typing each question, run every question through the API with its agent once the API is running with a hosted LLM. The full responses are saved to output/eval/agent_showcase/responses.jsonl, and this page is then updated from them. For scored pass rates over all 86 frozen questions, use python -m scripts.evaluation.evaluate_agent_api (see docs/agent_api_testing.html).

The expected figures come from the companies' XBRL filings and checked page readings. A response that gives the right figure from a different page, or rounded differently, still passes. A response that gives a figure the cited page doesn't show fails, even if the number is right.
