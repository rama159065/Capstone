Agent user guide and test book

How to use each agent of the Financial Report Copilot from Streamlit, which questions to ask, what the right answer is, and how to tell from the screen whether the answer can be trusted. The 77 question cards are the baseline for testing: each has the exact question to copy, the expected answer, the PDF page that proves it and a place to record your result.

Where the answers come from. Every question was run once on 23 November 2026 through Streamlit's own request, on the served index chroma_db_colab (509 annual reports, 143 companies, FY2022–FY2026) with the hosted Qwen3-8B. The expected figures were checked against the filings' pages (read by eye or by OCR where the PDF's text can't be copied) and the N-PORT database. Another run may word an answer differently; the figures, companies, years and pages shouldn't change. Another index can give different results. Many of these questions also guided the fixes, so this is a regression baseline, not a blind accuracy test.

While the agents work, the reply shows Thinking… with a running timer. When it is done, read it from top to bottom in this order.

2. The answer and its citations

Each figure carries a numbered source, [1] [2] …, listed under the answer by company, fiscal year and page. Thought for … s → Sources shows each source's chunk ID and a preview of its text. Read a chunk ID like this:

annual_report_edgar_ars_BAC_2025_p0133_vlm1
                        │   │    │     └ chunk on that page
                        │   │    └ page 133 of the PDF file
                        │   └ filing year
                        └ ticker
  • The page is the PDF page, the number in the PDF viewer's page box. It's often different from the number printed on the page: Chevron 2023 p31 is printed as page 39.
  • The year is the filing's year. Home Depot and Lowe's name a year by its start, so HD_2025 holds fiscal 2024.
  • nport_… is a row of the fund database, not a PDF page.
  • A chunk is only one part of a page, so the page is what you check.

3. The critic

The badge reads Critic: supported, next to 1/1 figures verified. The Critic support check card in Thought for … s → Checks gives the counts: Claims supported: 1/1 · Figures in the cited pages: 1/1.

  • Verdict: supported is needed for an answer. partially_supported leads to withholding.
  • Claims: a model judged each sentence. No claim count is normal for trend, sector, returns, dividend and some fund answers, because code wrote them; the critic step says so.
  • Figures: each number was looked for in the cited chunks. The two counts should match. A calculated number is accepted when it can be recomputed from cited figures.
Supported doesn't always mean correct. It means that the cited page says it. The page can still be about something else (see KN3). That is why every card has a page to open.

4. The agent panel

Trend, sector, returns, dividend and fund answers add a panel with the full table, one page or record per figure, and sometimes a chart. It also names what was left out and why.

5. The Thought for … s dropdown

Above each answer, collapsed. Its label sums up the run, for example Thought for 12.4 s · 8 steps · 4 searches · critic: supported.

Check an answer

  1. Click the page link on the card. It opens the filing at that page when this file is opened from the repo's docs folder (Edge or Chrome). If the link is blocked, open data\raw\financial_report_qa\annual_reports\<sector>\EDGAR_ARS_<TICKER>_<YEAR>.pdf.
  2. Find the row, then the year column, then the unit (“in millions”).
  3. If Ctrl+F doesn't find the figure, look with your eyes. Some filings' text can't be searched although the page displays correctly (for example Chevron 2022, Citigroup 2025, Costco 2025).
  4. For a calculation, redo the sum on the card with the page's figures. A difference in the last decimal is rounding.

Equivalent forms are the same answer: $3,097 million = $3.1 billion = 3,097 in a table in millions. (1,047) in brackets means −1,047.

How to ask

  • Name the company, the measure and the fiscal year: What was Bank of America's total assets in fiscal 2025?
  • Use the report's own words for the measure (total assets, net earnings, operating margin).
  • For a chart, say chart and the report year.
  • One question per message.

What to avoid

  • How is Bank of America doing? has no measure, so the clarifier asks for one.
  • Is Adobe's margin good? asks for an opinion. Ask for the margin.
  • Measures the report doesn't have, such as a bank's gross profit.

How to read the response

  • The line Critic support check should read supported, with all claims and all figures counted (for example 1/1 and 1/1).
  • In Thought for … s → Steps, the timeline should end with the critic and governance steps. A statement_search row means a statement row was also looked up.
  • The same answer may be worded differently on another run. Judge the figure, unit, company, year and page.
