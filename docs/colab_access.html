Opening the Colab-hosted Copilot from Your PC

The Streamlit UI and FastAPI run in Google Colab (colab_ingest_chroma_db.ipynb, cells 1–3 and 8–12) on the Chroma index restored from Drive. This page shows three ways to use them from a browser on your own PC for end-to-end testing.

Related: deployment.html §3.3 and §7.5, observability_langsmith.html, notebooks/README.md.

1. Summary

Pattern What runs where Who can open it Setup LangSmith trace starts at
A Colab port proxy Streamlit and FastAPI in Colab Only your signed-in Google account None: cell 9 prints the link Streamlit in Colab
B Cloudflare quick tunnel to Streamlit Streamlit and FastAPI in Colab Anyone with the link One extra cell Streamlit in Colab
C Local Streamlit, tunnel to FastAPI Streamlit on your PC; FastAPI, agents, Chroma and the LLM in Colab Only clients that send the API token One cell in Colab, four settings on the PC Streamlit on your PC

Which to use:

  • A for a quick check.
  • B when your network blocks Colab's proxy domain. This PC's network already blocks some Google download endpoints, so test A first.
  • C for the demo, or whenever you want one LangSmith trace from your own browser to the LLM.

In every pattern, Streamlit and FastAPI listen only on 127.0.0.1 inside the Colab VM (cp.serve). Nothing is reachable from outside until you open a proxy or a tunnel.

3. Pattern A: Colab's port proxy (no setup)

  1. Run cells 1–3 (restore the Chroma index from Drive), then 8 and 9.
  2. Cell 9 prints Open the chat UI: https://… from google.colab.kernel.proxyPort(8501). Open that link in your browser.
  3. If the page stays blank, run this in a new cell and use the window it opens:
from google.colab.output import serve_kernel_port_as_window
serve_kernel_port_as_window(8501)

Notes:

  • Only your Google account can open the link, and it works only while the notebook tab is open and connected.
  • After a disconnect, rerun cells 2, 3, 8 and 9 and use the new link. The old one stops working.
  • Turn on LangSmith tracing in the sidebar's Demo settings, or leave TRACE_EVERY_REQUEST on in cell 8.

4. Pattern B: Cloudflare quick tunnel to Streamlit

Run this cell after cell 9. It needs no Cloudflare account.

# Temporary public https link to Streamlit (stops when this runtime ends)
!wget -q -nc https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64 -O /content/cloudflared && chmod +x /content/cloudflared
import re, subprocess
tunnel = subprocess.Popen(["/content/cloudflared", "tunnel", "--no-autoupdate", "--url", "http://127.0.0.1:8501"],
                          stdout=subprocess.PIPE, stderr=subprocess.STDOUT, text=True)
for line in tunnel.stdout:
    if (m := re.search(r"https://[a-z0-9-]+\.trycloudflare\.com", line)):
        print("Streamlit:", m.group(0)); break
# stop it: tunnel.terminate()

Open the printed https://<random-name>.trycloudflare.com link on your PC. Streamlit's websocket works through the tunnel: cp.serve already starts Streamlit with --server.enableCORS false and --server.enableXsrfProtection false for proxying.

Security: anyone with the link can use the UI, and through it your LLM key's quota and your LangSmith project. Don't share the link, and run tunnel.terminate() when you're done. The link changes every time the tunnel starts.

5. Pattern C: Streamlit on your PC, FastAPI in Colab

Here your browser talks to a Streamlit running on your PC. That Streamlit calls the FastAPI in Colab through a tunnel, and the agents, Chroma retrieval and LLM calls run in Colab.

In Colab:

  1. Before cell 9, add a cell that sets an API token. Every request except /health and /docs then needs it.
import secrets
os.environ["API_AUTH_TOKEN"] = secrets.token_urlsafe(32)
print("API token (copy to the PC):", os.environ["API_AUTH_TOKEN"])
  1. Run cell 9: cp.serve passes the token to the API.
  2. Run the tunnel cell from pattern B, with 8501 changed to 8000. Copy the printed https://….trycloudflare.com URL.

On your PC (PowerShell, from the repo root):

$env:API_BASE_URL="https://<printed-name>.trycloudflare.com"
$env:API_AUTH_TOKEN="<token printed in Colab>"
$env:LANGSMITH_API_KEY="<your LangSmith key>"
$env:LANGSMITH_PROJECT="financial-report-copilot-colab"
streamlit run scripts\ui\api_streamlit_app.py

Open http://localhost:8501 and turn on LangSmith tracing in the sidebar's Demo settings. Before you open the UI, you can check that the API answers:

curl https://<printed-name>.trycloudflare.com/health

What you get: every request carries the token (X-API-Key), so the public API link is useless without it. Each question is one trace in LangSmith:

streamlit.conversation            your PC
└─ api.conversation_turn          Colab
   ├─ clarifier
   ├─ api.financial_report_qa.router → LangGraph steps → retrieve.financial_vlm (Chroma) → LLM calls
   └─ api.grounding_policy

Notes:

  • Use the same LANGSMITH_PROJECT on the PC as in Colab cell 8, so the whole trace lands in one project.
  • The local Streamlit needs the repo's Python environment (uv sync). It doesn't need the Chroma index or any models, because retrieval and the LLM run in Colab.
  • API_TIMEOUT_SECONDS (default 180) is how long the local Streamlit waits for an answer. Sector-trend questions can take longer; raise it if they time out.

6. Troubleshooting

Symptom Likely cause Fix
Pattern A link opens a blank page or "connection refused" Your network blocks Colab's proxy domain, or the notebook disconnected Try serve_kernel_port_as_window(8501); otherwise use pattern B or C
Streamlit shows "Please wait…" forever over the tunnel The websocket isn't getting through Check that Streamlit was started by cell 9 (cp.serve), which sets the proxy-friendly flags; restart the tunnel
401 / "API key required" from the local Streamlit API_AUTH_TOKEN differs between Colab and the PC Copy the token printed in Colab again; restart the local Streamlit
502 or 530 from trycloudflare The API or Streamlit in Colab has stopped, or the runtime disconnected Rerun cell 9, then start the tunnel again (the URL changes)
Answers come back not_grounded after about 60 s Request deadline too short for several LLM calls Keep REQUEST_TIMEOUT_SECONDS at 180 in cell 8, then rerun cell 9
The trace starts at api.conversation_turn, not streamlit.conversation The Streamlit process has no LANGSMITH_API_KEY Pattern C: set the key on the PC. Patterns A and B: cell 8 sets it for Colab's Streamlit
Tunnel cell prints nothing cloudflared couldn't connect out Rerun the cell; check tunnel.poll() and read tunnel.stdout for the error

7. When you're done

  1. Stop the tunnels: tunnel.terminate() (one per tunnel cell).
  2. Run cell 12 to stop Streamlit and FastAPI. The restored index stays on the runtime's disk, and the copy on Drive isn't touched.
  3. If you created an API_AUTH_TOKEN, it only lived in this runtime: a new session makes a new one.

Status, 20 November 2026: patterns A–C follow from how cp.serve binds the servers (127.0.0.1, Streamlit with CORS and XSRF off) and how the Streamlit app sends X-API-Key and LangSmith trace headers.
